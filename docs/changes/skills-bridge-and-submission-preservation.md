## Why

Audit of recent multi-agent competition sessions (`9a3e5855-446b-4007-87bb-02a185fc3fa7`, `3c6d8ebc-78ef-4d72-99f1-3390b54f5e35`, `bcb814a9-52cc-4bb9-98ac-9282e8a3bce4`) and independent adversarial audit via `/codex-cli` identified four operational friction points:
1. **The "Island Debate" Gap**: Multi-agent debates run extensively in chat subagents, but material empirical findings and adjudicated verdicts never get closed back into AI-Harness persistent task memory (`record_research_insight`).
2. **Missing Artifact Preservation**: Ad-hoc submissions generated by custom pipelines, external clusters, or debate outputs were left loose in the workspace root without audit fingerprinting or tracking because `register_submission()` strictly requires an experiment directory with plugin test predictions. A safe, unverified file preservation path was missing.
3. **PowerShell Quote Stripping on Schema Examples**: `ai-harness-agent schema` displayed inline `--params '{"key": "val"}'` JSON examples which suffer severe quote corruption on Windows PowerShell terminals, and `_parse_dynamic_kv_args` silently dropped unconsumed positional arguments.
4. **Alarming Scorer Mismatch Warnings**: When `paths.metrics_evaluator` is intentionally declared, the runner emitted alarming warnings on every fold about generic evaluation failures, even though the configured custom scorer was authoritative.

## What changed

- **`tools/agent_bridge_cli.py`**:
  - Formatted `_format_action_schema` using flat kebab flags (`--flag <value>`) and added Windows PowerShell quoting instructions.
  - Hardened `_coerce_value` to reject NaN/inf float coercion (preserving string identity).
  - Hardened `_parse_dynamic_kv_args` to raise `ValueError` on unconsumed positional arguments rather than silently dropping them.
  - Updated `cmd_act` to report argument errors cleanly via `parser.error`.

- **`harness/submission_manager.py`**:
  - Implemented `preserve_file_submission()`: copies artifact to `submissions/sub_xxx_preserved/`, computes payload SHA-256, verifies copy integrity, and writes `PRESERVATION_RECEIPT.json` (`record_type: "preservation_only"`, `verification_status: "unverified"`, `dispatch_authorized: False`, `status: "PRESERVED_UNVERIFIED"`).
  - Updated `render_submissions_markdown()` to render `📦 `PRESERVED`` without displaying as `LOCAL_VERIFIED`.

- **`harness/bridge_common.py`**:
  - Registered `TypedActionName.PRESERVE_SUBMISSION = "preserve_submission"` with `ApprovalTier.AUTO`.
  - Added schema specification to `TYPED_ACTION_SCHEMAS`.

- **`harness/agent_bridge.py` & `harness/bridge_actions.py`**:
  - Added routing and handler `_handle_preserve_submission` to execute preservation via Agent Bridge.

- **`harness/runner.py`**:
  - Added informational notice: `[ai-harness] INFO: Custom metric scorer active: <metric> via <hook>`.
  - Converted generic evaluation skip warning to informational log when custom metric scorer is authoritative.

- **`harness/skill_injector.py` & Global Skills**:
  - Added "Close the loop into AI-Harness" guidance in `/harness` template, `/debate` template, and `debate-team/SKILL.md`.
  - Refreshed global skills via `python -m harness.skill_injector --global`.

- **`tests/test_preserve_submission.py`**:
  - Added 5 unit tests verifying preservation integrity, receipt schema, score validation, bridge action execution, CLI parsing, and runner notice logging.

## Approach

Following the recommendations of the independent `/codex-cli` audit:
- Kept submission preservation strictly separated from verified pipeline packaging. Preserved files are marked `PRESERVED_UNVERIFIED` and cannot bypass dispatch gates or burn leaderboard quota.
- Preserved the existing status rules: debate consensus remains a `hypothesis` until supported by a machine-evaluated `DecisionRuleV1` receipt.
- Maintained backward compatibility and schema compliance across all components.
